# ここにGPTの価格CSVを置く

GPTが出したCSV(例 `prices_20261009.csv`)を、このフォルダにアップロードするだけで、
1〜2分後に `data/prices.json` と `data/prices_long.csv` が自動で作り直され、サイトに反映されます。

- 処理したCSVは `data/archive/` に移ります。
- CSVに決まり違反(購入可なのに価格が空、など)があると更新は止まり、GitHubからメールが届きます。サイトは前の状態のままです。
- 同じ日付のCSVをもう一度置くと、新しい方で置き換わります。
- 進み具合はリポジトリの「Actions」タブで見られます。
