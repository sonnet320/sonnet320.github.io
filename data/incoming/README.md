# ここにGPTの価格CSVを置く

GPTが出したCSV(例 `prices_20261009.csv`)を、このフォルダにアップロードするだけで、
1〜2分後に `data/prices.json` と `data/prices_long.csv` が自動で作り直され、サイトに反映されます。

- 処理したCSVは `data/archive/` に移ります。
- CSVに決まり違反(購入可なのに価格が空、など)があると更新は止まり、GitHubからメールが届きます。サイトは前の状態のままです。
- 同じ日付のCSVをもう一度置くと、新しい方で置き換わります。
- 進み具合はリポジトリの「Actions」タブで見られます。

## ファン・CPUクーラー・ケースの価格(PC構成シートとランキングに入る)
- CPU・GPU・SSD と同じCSVに混ぜてよい。カテゴリは `ファン` / `CPUクーラー` / `ケース`、製品IDは `fan-…` / `cooler-…` / `case-…`。
- これらは `data/parts.json` に入り(価格推移ページには出ない)、`data/sheet-prices.json` に
  「PC構成シート・ランキングの製品ごとの、いちばん新しい調査日の在庫ありの最安値」として結び付けられる。
  サイトのPC構成シートとランキングは、開いたときにこの価格を使う(見つからない製品はシートの目安のまま)。
- 製品名で自動的に結び付ける。結び付かなかった製品は Actions のログに警告が出るので、
  `data/id-map.json` に「CSVの製品ID → シートのID」を足す(Claude に頼めば足します)。
- シートに無い製品の価格は使われない。新しい製品はまず Claude がシートに追加する。
