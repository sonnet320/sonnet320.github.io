# サイトから「データを使わないでほしい」と連絡が来たときの手順

方針(2026-10-14、そねっとさんの判断):規約や宣言で禁止されていない出典の値は、出典付きで使い続ける。
サイトから削除を求められたら、すぐに外す。この手順はそのためのもの。

## 共通の流れ

1. 連絡をくれたサイトのドメイン(例 `computerbase.de`)を確認する
2. `python tools/remove_source.py ドメイン` で、何が外れるか・ほかにどこに出てくるかを表示する(変更はしない)
3. `python tools/remove_source.py ドメイン --apply` で、CPU の消費電力の値を外す
4. 下の「出典ごとの手作業」を行う
5. 計算の値が変わったら `DIAG_VER` を上げ、おすすめBTOを計算し直す(README の「シートの計算を変えたとき」)
6. 検証記録の該当する数値の表と出典URLを消し、`_dev/HANDOFF.md` の「使わない出典」に追加する(値そのものは記録に書かない)
7. PR にして Merge したら、サイトに「外しました」と返信する
8. 価格データなら、`tools/make_prices.py` の `EXCLUDED_STORES` に店名を足す(過去の価格も含めて外れる)

## 出典ごとの手作業

| 出典 | スクリプトで外れるもの | 手で外すもの |
|---|---|---|
| ComputerBase | CPU の消費電力(約120件) | なし(検証記録の比較の表は消す) |
| hwcooling.net | なし | GPU のチップごとの補正 `k`(`GPU_CHIPS` の `k` を外すと 1.0 に戻る)と `GPU_CALIB_SRC` の表示、ファン口径(`GPU_FAN_D`)・最大回転数(`GPU_FAN_MAX`)のうち hwcooling 由来のもの(どれかは `gpu_fan_diameter_20261013.md`・`gpu_fan_maxrpm_20261013.md` の表)。補正を外すと GPU 温度が大きく変わるので、作者のPCの実測(RTX 5080)に合うか確認する |
| gpureport.cz | なし | ファン口径・最大回転数のうち gpureport 由来のもの(同じ表)、GPU のファン%の換算表(`gpu_calib_chips_20261013.md`) |
| Cybenetics | なし | ARCTIC のファンの騒音(`FAN_NOISE` の `cyb` の付いた7件。外すと「騒音値なし」になる)と、シート・ファンランキングの出典一覧(`NOISE_SRC`)。PQ 曲線の平均の形も Cybenetics の測定が大部分なので、外す場合は 3D のファンの曲線を以前の放物線の形に戻す(大きな変更) |
| メーカー(仕様) | なし | ファン・クーラーの仕様(`src` にそのメーカーの URL がある行)。外すと一般的な値になるか、製品をリストから外す |
| 販売店(価格) | なし | `EXCLUDED_STORES` に追加し、`data/incoming/` の扱いと GPT への価格調査の依頼から外す |
| エルミタージュ秋葉原・自作日和・ASCII など(ケースの構造) | なし | `pc-sheet/index.html` の `CASE_MODELS` の該当ケースのコメントと、そこから決めた値。外した部分は「仮定」と表示する(`note`) |

## 連絡を受け取れるようにする

- サイトの「お問い合わせ」のリンク(`config.json` の `contactUrl`)は空欄で、今は表示されていない。問い合わせフォームやメールの窓口を決めたら入れる
