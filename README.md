# PC構成シート Webサイト

2026-10-06 制作。既存のVersion 56をもとに、ホームページとシートの連携を追加しています。

## GitHub Pagesへの掲載

1. ZIPを解凍します。
2. `publish/` の中身（index.html、assets、pc-sheet、presets、results、config.jsonなど）を、`sonnet320/sonnet320.github.io` の直下に置きます。`publish` というフォルダごと置かないでください。
3. GitHubの「Add file → Upload files」で、フォルダ構造を保ってアップロードします。既存の「準備中」のindex.htmlはこのindex.htmlに置き換えます。
4. 公開後は https://sonnet320.github.io/ でホームページ、https://sonnet320.github.io/pc-sheet/ でシート単体を開けます。

この納品時点ではリポジトリへのアップロード・公開更新は行っていません。
`development/` は更新担当者向けです。公開リポジトリに置かないでください。元のソース一式、research/、fancurve/ の個別曲線も公開対象に含めていません。

## 表示内容

上に構成シート、下の左にBTO構成カード、右に計算済みのエアフロー図・CPU/GPU/VRM温度・評価を置いています。
幅900px以上ではシート内をスクロールし、900px未満ではシートの高さに合わせてページ全体をスクロールします。下段にシミュレーションをもう一つ起動せず、保存した結果を表示します。

4件の表示サンプルは販売商品や実売価格ではありません。価格は未登録です。価格帯はレイアウト確認用の配置です。実際のBTO掲載に使う場合は次の設定を差し替えてください。

## config.jsonで変更する項目

- `siteName`: チャンネル名
- `channelUrl`: YouTubeチャンネルの正規URL。空欄のときリンクを表示しません。
- `contactUrl`: お問い合わせのURL。空欄のときリンクを表示しません。
- `menu`: `label` と同じページ内の `href`（例 `#sheet`）
- `products`: 下段に掲載する構成の一覧

商品ごとの項目:

| 項目 | 内容 |
|---|---|
| id | 重複しない構成ID |
| name / shop / model / grade | 表示名・ショップ・モデル・グレード |
| cpu / gpu / memory / ssd / cooler / case | カードに表示する仕様 |
| price | 税込価格の数値。未登録は null |
| priceDate | 価格を確認した日付（例 2026-10-06） |
| tier | 価格未登録のときの配置用。20 / 30 / 40 / plus |
| sample | 表示サンプルは true。実際の掲載商品は false |
| genericCase | 汎用ケースによる計算なら true |
| preset | 構成JSONへの相対パス |
| result | 計算結果JSONへの相対パス |
| affiliateUrl | ショップのアフィリエイトURL。未登録は空文字 |
| pr | PR対象は true |

実際の価格が登録されている商品は、20万円以下、20万円超〜30万円以下、30万円超〜40万円以下、40万円超に振り分けます。タブの表示名は合意した「20万円以下／30万円以下／40万円以下／40万円以上」です。40万円ちょうどは40万円以下に入ります。
ショップのリンクにはPR表記を付けます。サンプルにショップの購入リンクは表示しません。
商品価格を掲載するときはpriceDateも必ず入力してください。

## 構成を追加・再計算する

1. シートで構成・ケース・ファン・室温・負荷を入力します。
2. 「データをコピー」で得たJSONを、`presets/商品ID.json` の `state` に保存します。既存ファイルの形式を参考にしてください。
3. 「計算結果を書き出す」を押すと、2Dで静止状態から6秒計算し、続く2秒の平均を取ったJSONをダウンロードします。図もJSON内に含まれます。
4. このJSONに `presetId`（商品ID）を加えて `results/商品ID.json` に置きます。JSON内のstateは右側の表示には不要なので削除できます。
5. config.jsonの商品を追加し、preset/resultのパスを指定します。ケースを差し替えた場合も必ず再計算してください。

`pc-sheet/?preset=sample-30` のように、構成IDをURLで指定して開くこともできます。IDは半角英数字・ハイフン・アンダースコアです。

## 注意・確認状況

- 温度・風量・騒音・評価は既存モデルによる目安です。掲載結果は2D・5mm格子・室温25°C・CPU/GPU負荷100%・ケースファン70%です。各結果に条件を保存しています。
- 140mmファンのHUBDAMP修正は、元のVersion 56と同じく無効です。再較正は行っていません。
- 3D機能を保持しています。WebGPU対応が必要です。今回の検証環境ではWebGPUアダプターが取得できず、3D計算の実動作と速度は未確認です。実機でご確認ください。
- PC幅1440pxとスマホ幅390pxで、カード選択・価格帯切り替え・シートへの構成読込・スマホの高さ通知・ページの横はみ出し・クエリーによる構成読込を確認しています。実際のスマホ端末での確認は未実施です。
- 既存のCPU・追加ファン・騒音に関するテスト（smoke22〜24）は通過しています。
- ブラウザに構成を自動保存する仕様を保持しています。独立した診断カードとClaudeの共有DBは公開用シートから無効化済みです。
- シートの項目は削っていません。スマホでのシート短縮は、項目の選定後に対応できます。
- 外部ファイルを読み込むため、index.htmlを直接ダブルクリックする方法では全機能が動きません。公開URLかローカルHTTPサーバーで確認します。ローカルなら、このフォルダで `python -m http.server 8000` を実行し http://localhost:8000/ を開きます。
